# 与 wiki 的对接

## 页面清单

| 文件 | wiki 页面 | 说明 |
| --- | --- | --- |
| `lua/generated/Module_Data_Layer_Temperature.lua` | `Module:Data/Layer_Temperature` | 数据模块，`build` 产出，**不要手改** |
| `lua/wiki/Module_温度平滑折线图.lua` | `Module:温度平滑折线图` | 折线图渲染，读数据模块 |
| `lua/wiki/Module_温度横向表格.lua` | `Module:温度横向表格` | 横向表格渲染，读数据模块 |
| — | `Template:地层温度` | 不用改，仍然把 `{{{1}}}` 转给上面两个模板 |

`Template:温度平滑折线图` 与 `Template:温度横向表格` 也不用改，它们只做 `{{#invoke:...|main}}`。
界面上还依赖 `Module:平滑折线图`（ECharts 代码生成）与 `Template:地层温度` 的 `<noinclude>` 示例，二者保持原样。

## 调用方式

```wikitext
{{地层温度|wasteland}}          →  横向表格 + 折线图
{{地层温度|辐射废土}}            →  同上（中文名可用）
{{地层温度|Wasteland}}          →  同上（旧写法仍然有效）
{{温度平滑折线图|wasteland|showLabel=false|points=360}}
{{温度横向表格|wasteland|maxgap=60}}
```

数据模块的索引接受 **id / 中文名 / 英文名**，大小写与空格不敏感（`Gravel_Lands`、`gravel lands`、`GRAVEL_LANDS` 等价）。

参数：

| 参数 | 作用于 | 默认 | 说明 |
| --- | --- | --- | --- |
| `showLabel` / `showMarkPoint` / `showMarkLine` / `showAllPoints` / `useGradient` / `threshold` | 折线图 | 见 `模块:平滑折线图` | 与原实现一致 |
| `points` | 折线图 | 240 | 采样段数，产出 `points + 1` 个点 |
| `maxgap` | 表格 | 周期的 1/12 | 相邻两列的最大时间跨度（秒），越小列越密 |

## 与旧实现的行为差异

1. **不再预存采样点。** 折线由关键帧现算，列由关键帧 + 折返点 + 段内补点生成。
2. **折线覆盖进入地层的头几秒。** 旧数据从首帧时间（如 16.10 s）开始，新的从 0 开始，按 `preWrapMode` 折返，
   与游戏里 `Evaluate(0)` 一致。
3. **表格着色用真实极值。** 曲线会过冲出关键帧范围（深林丛渊最低 5.63 °C、干旱沙漠最高 35.65 °C），
   旧的"最高/最低"只看采样行，会漏。
4. **变化率现算。** 由曲线的解析导数给出，不再依赖预存的 `°C/分` 列。
5. **周期文本来自数据。** 地热喷口的周期现在是 3:59（旧文档与旧模板里写的是 18:59，那是 8 月旧曲线的值）。
6. **接受 id 与中文名。** 旧的只接受英文名，且大小写敏感；用 `{{地层|id=gravel_lands}}` 里的 id 会直接报错。

## 迁移步骤

1. 上传 `Module:Data/Layer_Temperature`（数据本身）。此时还没换渲染模块，页面不受影响。
2. 上传 `Module:温度平滑折线图` 与 `Module:温度横向表格`。两者只依赖数据模块的新接口。
3. 检查 `砾石荒原`、`深层砾石带`、`干旱沙漠`、`辐射废土`、`深林丛渊` 五个页面的温度小节，以及沙盒页。
4. 回滚：把两个渲染模块恢复旧版本即可；数据模块新旧格式互不兼容，回滚时一并恢复。
